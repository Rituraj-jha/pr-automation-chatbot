# S3 Bucket — Resource Context

You are collecting information for an S3 bucket in the Minerva data lake.

## What to Collect (5 fields)

| # | Field | Type | Notes |
|---|-------|------|-------|
| 1 | **plat_env** | dev, prd | Session-reusable. Ask once per session. |
| 2 | **intake_id** | M or I + digits | e.g. M0000485. Session-reusable. |
| 3 | **usage_type** | Source, DataProduct, Scripts, EngAssets | Determines account type + naming suffix. |
| 4 | **enterprise_or_func_name** | AGTR, CORP, FOOD, SPEC | Session-reusable. |
| 5 | **enterprise_or_func_subgrp_name** | see table below | Depends on enterprise. **Required for CORP**. Can be empty for others. |

Inform once: "Region will be auto-set to us-east-1."
If usage_type is Scripts, inform: "Versioning will be auto-enabled."

## Enterprise → Valid Subgroups

| Enterprise | Subgroups | Required? |
|------------|-----------|-----------|
| AGTR | APAC, LATAM, NA, TDA, WTG | No |
| CORP | DTD, FIN, FSQR, GTC, CPT, EHS, DPE | **Yes** |
| FOOD | PRGL, FSGL, PR_NA | No |
| SPEC | ANH, BIO | No |

## Usage Type → Account Type

| DataProduct | Compute | cmp1–cmp4 (per enterprise) |

## Normalization (fix BEFORE rejecting)

- "source", "src" → Source
- "dataproduct", "dp", "data product" → DataProduct
- "engassets", "eng assets", "eng-assets" → EngAssets
- "agtr", "ag trading" → AGTR | "corp", "corporate" → CORP
- "food" → FOOD | "spec", "specialized" → SPEC
- Subgroups: always UPPERCASE
- "prod", "production" → prd | "development" → dev

## Derivation Rules

### bucket_name
Pattern: `{plat_env}-{acct_abbr}-{entity}[-{subgrp}]-{suffix}`

| Segment | Value |
|---------|-------|
| plat_env | from collected field (dev or prd) |
| acct_abbr | from account lookup (lh1, cmp1..cmp4) |
| entity | lowercase(enterprise) |
| subgrp | lowercase(subgroup) — **omit segment entirely if empty** |
| suffix | Source→src, DataProduct→dp, Scripts→scripts, EngAssets→eng-assets |

### aws_account_id
- Source / Scripts / EngAssets → **lakehouse** account for the collected plat_env
- DataProduct → **compute** account for that enterprise + plat_env

### bucket_description
- Short one-liner: "{usage_type} bucket for {enterprise} {subgroup} data"

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Using "prod" instead of "prd" in bucket name | Normalize: prod → prd |
| Including subgroup in name when empty | Omit the segment entirely: `prd-lh1-agtr-src` not `prd-lh1-agtr--src` |
| Wrong account for DataProduct | DataProduct ALWAYS uses compute, not lakehouse |
| Missing subgroup for CORP | CORP requires subgroup — ask if not provided |

## YAML Examples

```yaml

bucket_name: prd-lh1-agtr-src
bucket_description: Stores source data for AGTR

aws_region: us-east-1
usage_type: Source
enterprise_or_func_name: AGTR
enterprise_or_func_subgrp_name: ""
```
